## Legacy Release Snapshot

This directory is not the active deployment source for `autosocial.tech`.

Current deployment docs in the project root (`DEPLOY_ADMTOOLS.md`) specify:
- deploy frontend from the root `frontend/` directory
- deploy backend from the root backend files (`app.py`, `saas_api.py`, `saas_services.py`, `stripe_service.py`, etc.)

Use this folder only as a historical snapshot/reference.

Do not deploy pricing, plan logic, or frontend assets from `deploy/release/` without re-syncing them with the active root codebase.
