# History

Internal working documents from earlier phases of this project: changelogs,
release-readiness snapshots, an earlier deployment checklist, dated QA/audit
session logs ("Iteration N" style, tied to a specific branch and date), and
the session log of the pivot from a public social-media SaaS tool to today's
private YouTube video factory. Kept for real historical record, not deleted;
moved out of the repository root (and out of `docs/`) because they're
superseded by the current, maintained docs — `README.md`, `ARCHITECTURE.md`,
`SYSTEM_DESIGN.md`, `PRODUCTION.md`, `DEPLOYMENT.md`, `TESTING.md`,
`OPERATIONS.md`, `SECURITY.md`, `CASE_STUDIES.md`, `ENGINEERING_DECISIONS.md`,
`LESSONS_LEARNED.md`, `PERFORMANCE.md`, and `docs/adr/` — and would otherwise
clutter the first thing a reviewer sees. Nothing in this folder should be
treated as current guidance; where a fact here conflicts with a doc listed
above, the doc above wins.
