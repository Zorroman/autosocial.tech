# History

Internal working documents from earlier phases of this project — changelogs,
release-readiness snapshots, an earlier deployment checklist, and the
session log of the pivot from a public social-media SaaS tool to today's
private YouTube video factory. Kept for real historical record, not deleted;
moved out of the repository root because they're superseded by the current,
maintained docs (`README.md`, `ARCHITECTURE.md`, `DEPLOYMENT.md`,
`OPERATIONS.md`, `docs/DEMO-READINESS.md`) and would otherwise clutter the
first thing a reviewer sees. Nothing in this folder should be treated as
current guidance.
