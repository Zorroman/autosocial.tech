# Code of Conduct

This is a solo portfolio project (see [`CONTRIBUTING.md`](CONTRIBUTING.md) for
what that means in practice — it's not accepting code contributions under its
[license](LICENSE)). The interaction surface here is small: issues, and any
discussion that comes out of a technical review or interview. The standard
still applies to it.

## Expected

- Be direct and specific. "This claim in `SYSTEM_DESIGN.md` doesn't match the
  code at `longform_render.py:120`" is far more useful than "this seems off."
- Assume good faith about mistakes in the code or docs — a lot of this repo
  documents mistakes that were found and fixed, on purpose.
- Keep technical criticism about the work, not the person.

## Not acceptable

- Harassment, personal attacks, or discriminatory language, in issues or any
  other communication about this project.
- Bad-faith engagement — reporting spam, or opening issues to make a point
  unrelated to the project.

## Enforcement

Since this repository doesn't have an open contributor community, enforcement
is simple: reports of the above go through the same channel as a security
report (see [`SECURITY.md`](SECURITY.md)), and violating content will be
removed/blocked at the maintainer's discretion.
